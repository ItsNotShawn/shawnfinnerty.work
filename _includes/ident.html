{%- comment -%} A channel "ident": your own animation for a channel, set in _data/channels.yml. ident: path to a video (.mp4/.webm), animated .gif/.webp, or still image ident_poster: optional still frame shown before a video loads / when Motion is off ident_mode: "loop" (plays while on screen) or "scroll" (video scrubs as the page scrolls) Until `ident` is set, a no-signal card with the channel name is shown. Usage: {% include ident.html channel=ch size="tile" %} (size: tile | band) {%- endcomment -%} {%- assign ch = include.channel -%} {%- assign ext = ch.ident | split: "." | last | downcase -%} {%- assign is_video = false -%} {%- if ch.ident -%}{%- if ext == "mp4" or ext == "webm" -%}{%- assign is_video = true -%}{%- endif -%}{%- endif -%} {%- if is_video %} {%- elsif ch.ident %} {%- else %} {%- endif %} CH {{ ch.number }} {{ ch.name }}
